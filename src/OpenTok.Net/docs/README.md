## OpenTok.Net

Thank you for installing OpenTok.Net. This is the umbrella package: on an `-ios` target framework it
brings in `OpenTok.Net.iOS`, on an `-android` target framework it brings in `OpenTok.Net.Android`.
Install it directly in a multi-headed MAUI app instead of picking the platform package yourself.

For details and issue reporting, see the repository: https://github.com/sbokatuk/OpenTok.Net

### WIKI and API

- iOS: https://tokbox.com/developer/sdks/ios/
- Android: https://tokbox.com/developer/sdks/android/
